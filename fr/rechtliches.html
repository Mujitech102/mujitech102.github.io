Protection des données et mesure des visiteurs

Demandes de contact

Si vous nous contactez, nous utiliserons les informations fournies pour traiter votre demande et coordonner la commande. Les formulaires en ligne sont soumis via FormSubmit à info@mujitech.ch. Veuillez ne pas transmettre de mots de passe ou de données particulièrement sensibles. Alternativement, vous pouvez nous contacter directement par email ou par téléphone. Informations sur le service du formulaire : Protection des données FormSubmit.

Hébergement

Ce site Web est fourni via les pages GitHub. Lors de l'accès, des données techniques de connexion sont collectées par l'hébergeur. De plus amples informations peuvent être trouvées dans le Politique de confidentialité de GitHub.

Statistiques facultatives avec Google Analytics

Nous chargeons Google Analytics uniquement si vous autorisez les cookies statistiques. Les pages vues, la profondeur de défilement, les clics de contact et les interactions avec les formulaires sont mesurés pour améliorer le site Web. Le contenu du formulaire, les noms, les adresses e-mail, les numéros de téléphone et les informations de connexion ne sont pas envoyés à Analytics par notre code de mesure. Les requêtes et fragments d'URL sont supprimés des adresses de page mesurées. La personnalisation des annonces et les signaux Google sont désactivés dans le code du site Web. Google peut traiter des données techniques de connexion et d'utilisation ; le traitement à l’étranger est possible. Informations : Protection des données Google.

Vous pouvez à tout moment refuser les statistiques ou modifier votre choix . Votre sélection est enregistrée localement dans le navigateur. Si vous révoquez votre consentement, les cookies d'analyse accessibles seront supprimés et la mesure sera désactivée.

Vos demandes

Pour information, correction ou suppression des informations que vous nous avez fournies, veuillez contacter info@mujitech.ch. Les données de commande sont utilisées dans le cadre du traitement et du stockage requis.
